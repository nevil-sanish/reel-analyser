# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email **nevilsanish@gmail.com** with the subject "Security", and include:

- what you found and where (file, screen or version),
- how to reproduce it,
- what an attacker could do with it.

You will get a reply within 7 days. Once the problem is confirmed, a fix is released as soon as practical, and you are credited in the release notes if you want to be.

## Supported versions

Only the latest release on [GitHub Releases](https://github.com/nevil-sanish/reel-analyser/releases) (and the same version on F-Droid) gets security fixes.

## Scope

In scope: the Android app (both the Full and Semi builds) and the code in this repository, including how API keys are stored and sent, the in-app updater and the Accessibility service.

Out of scope: the services the app talks to (Instagram, YouTube, LinkedIn, the AI providers, GitHub, Codeforces, LeetCode, Buy Me a Coffee, UPI apps). Report problems in those to their owners.
